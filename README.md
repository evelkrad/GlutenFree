## GlutenFree
Gluten Free Game - TFG

Este proyecto es un videojuego de plataformas en 2D desarrollado con [Python](https://www.python.org/) y [Pygame](https://www.pygame.org/). Está orientado a la concienciación sobre la celiaquía de forma educativa y entretenida.

## Características

- Motor de juego en 2D con físicas básicas
- Sistema de puntuación
- Enemigos con inteligencia básica
- Múltiples plataformas generadas aleatoriamente
- Menú de pausa, controles y pantalla de Game Over
- Uso de recursos audiovisuales generados por IA

## Requisitos

Tener instalado Python 3.10+
Conexión a internet para instalar dependencias
Sistema operativo Windows, macOS o Linux


## Instalación Python

Descarga Python desde su web oficial:
https://www.python.org/downloads/

Durante la instalación:
Marca la opción "Add Python to PATH" ✔
Luego pulsa "Install Now"

## Descarga del juego

Descarga el juego (ZIP o carpeta del proyecto).
Descomprime el archivo y colócalo, por ejemplo, en tu escritorio.

## Abre una terminal en la carpeta del juego

En Windows:
Navega hasta la carpeta donde está el archivo main.py
Haz clic derecho en un espacio vacío
Elige “Abrir en Terminal” o “Abrir ventana de PowerShell”

En macOS / Linux:
Abre la Terminal
Usa cd para entrar en la carpeta del juego (ejemplo):
cd ~/Escritorio/GlutenFreeQuest/code

## Instala dependencias

pip install pygame pygame-ce pytmx moviepy

Una vez instaladas las librerías, ejecuta:
python main.py
